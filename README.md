# Breast Cancer Cell Research Project

Project structure for working with the BreakHis breast cancer histopathology dataset.

## Structure

- `data/raw/BreakHis_v1/`: raw BreakHis dataset files
- `metadata/`: dataset metadata and generated annotations
- `src/data/`: data loading and preprocessing code
- `notebooks/`: exploratory analysis and research notebooks
- `requirements.txt`: Python dependencies
